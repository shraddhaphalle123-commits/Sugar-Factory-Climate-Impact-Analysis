# Sugar-Factory-Climate-Impact-Analysis
Python project to analyse the impact of temperature and rainfall on sugarcane production and sugar factory operations.
Sugar Factory Climate Impact Analysis

Project Overview

This project analyses how climate change affects sugar factories by studying environmental factors such as temperature and rainfall.

Objectives

- Analyse temperature variations.
- Study rainfall conditions.
- Understand the impact of climate change on sugarcane production.
- Estimate potential effects on factory operations.

Technologies Used

- Python
- Conditional Statements
- Basic Data Analysis

Input Parameters

- Temperature (°C)
- Seasonal Rainfall (mm)

Output

The system displays climate suitability scores and an overall climate impact condition.

Project Type

Academic Project
